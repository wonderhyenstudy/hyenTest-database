데이터를 다루기 위해 SQL언어를 사용
데이터 정의(DDL) , 데이터 조작(DML)

데이터 정의(DDL) 
CREATE TABLE 테이블명 (
    컬럼명1 데이터타입 ,
    컬럼명1 데이터타입 ,
);
CREATE               테이블(구조) 생성
VARCHAR2, NUMBER    데이터 타입

INSERT  데이터 삽입
SELECT  데이터 조회

INSERT INTO 테이블명 VALUES('값1', '100');
SELECT * FROM 테이블명;

데이터 모델 : 현실 세계의 정보를 컴퓨터 안에서 표현하는 방법
계층형 모델       : 트리구조/부모-자식 1:N관계/상하관계 명확,단방향      
네트워크형 모델    : 그래프 구조/복잡한 N:M 관계 가능/포인터기반
관계형 모델        : 테이블(표) 구조/가장대중적, 유연성/오라클포함
객체 지향형 모델   : 객체구조/복잡한 데이터타입 처리유리/클래스,상속개념포함

관게형 데이터베이스와 SQL언어를

주요 자료형(data type)
VARCHAR2(n)    : 가변 길이 문자열(n 최대길이) / 이름, 주소, 제목 등 길이를 예측할 수 없는 일반적인 텍스트
CHAR(n)        : 고정 길이 문자열 / 성별, 주민번호, 국가코드 등 일정한 길이
NUMBER(p, s)   : 숫자형(p:전체 자리수, s:소수점 이하 자리수) / 정수, 징수, 금액 등 모든 숫자형 데이터
DATE           : 날짜와 시간 저장 / 가입일, 수정일, 생년월일 / 산술 연산 가능 7바이트 고정크기
CLOB           : 텍스트 데이터 대용량 저장용 / VARCHAR2의 최대 크기를 넘어서는 긴 글 / 게시글 본문, 약관 내용, 제품 상세 설명 등 긴 텍스트
BLOB           : 이진 데이터 저장(이미지, 파일 등)
